# project-
Expressive Chatbot

Project Overview

An emotion-detection chatbot that identifies facial expressions and responds according to the detected emotion.

Features

* Facial expression detection
* Emotion-based chatbot responses
* Graphical user interface using Python Tkinter

Technologies Used

* Python
* OpenCV
* DeepFace
* Tkinter

How to Run

1. Install the required Python libraries.
2. Open the project folder in VS Code.
3. Run chatbot.py.
